## 1. Build caches and runtime state — ~437 MB, zero risk

All already gitignored, so this is disk hygiene, not repo hygiene. Every one
is regenerated by a command you already run.

| Path | Size | What it is | Regenerate with |
|---|---|---|---|
| `web/node_modules/` | 323 MB | npm packages | `cd web && npm install` |
| `web/.next/` | 97 MB | Next.js build cache | `npx next build` |
| `var/sentinel.db` | 14 MB | SQLite — my test runs, not your data | `python -m backend.train` |
| `web/out/` | 2.6 MB | **stale** static export — contains pre-redesign pages | `npx next build` |
| `var/artifacts/` | 2.2 MB | trained model artifact | `python -m backend.train` |
| `var/uploads/` | 432 KB | content-addressed uploaded CSVs | re-upload |
| `web/tsconfig.tsbuildinfo` | 91 KB | TypeScript incremental cache | `npx tsc` |
| `**/__pycache__/` | small | Python bytecode | automatic |

```bash
# safe, from the repo root
rm -rf web/.next web/out web/tsconfig.tsbuildinfo
find . -name __pycache__ -not -path './.venv/*' -not -path '*/node_modules/*' -exec rm -rf {} +

# heavier, only if you are done developing for a while
rm -rf web/node_modules          # then: cd web && npm install
rm -rf var/                      # then: python -m backend.train
```

> `web/out/` is genuinely stale — it was exported before the console redesign
> and still holds pages that no longer exist. Delete it; a rebuild is correct.

> **`var/` is the only one carrying state you might care about** — the
> screening runs, audit trail and uploaded datasets from my testing. It is all
> reproducible from the shipped dataset, but check before deleting if you have
> done runs of your own.

**Not in this list: `.venv/` (831 MB).** Regenerable from
`requirements.txt`, but you need it to run anything. Leave it.

## 2. Unused npm dependencies — 36 MB, verified safe

Five packages are declared in `web/package.json` and imported by **zero**
files. `recharts` appears twice in the source, both times inside a comment
saying it is *not* used.

| Package | Size | Imports found |
|---|---|---|
| `lucide-react` | 28 MB | 0 |
| `recharts` | 5.1 MB | 0 (2 comment mentions only) |
| `framer-motion` | 3.1 MB | 0 |
| `class-variance-authority` | 64 KB | 0 |
| `postcss-load-config` | 68 KB | 0 |

**Verified:** I removed all five, ran `npx next build` — it compiled and
generated all 7 static routes cleanly — then reverted. Bundle size was
unchanged, which is expected: unused packages were already tree-shaken out.
The win is install time and `node_modules` size, not runtime.

```bash
cd web && npm uninstall recharts framer-motion lucide-react \
  class-variance-authority postcss-load-config
```

**If you do this, also fix two now-false comments** that say recharts is in
`package.json`:
- `web/src/components/lab/plot.tsx:7`
- `web/src/components/charts/charts.tsx:6`

Charts are hand-drawn inline SVG on the `Frame`/`scale`/`Tick`/`LimitLine`
primitives in `plot.tsx`. That is a deliberate choice, not an oversight — an
instrument plot places every tick and limit line on purpose, and bending a
generic chart library into that shape costs more code than drawing it.

**Also worth adding** (currently missed by `.gitignore`):
```
web/*.tsbuildinfo
```

  `generate_burnin_dataset.py`, the four rows from the README table, and
  trimming `FILES` in `tests/test_generator.py:23`.

Until you decide, leaving them costs nothing.
